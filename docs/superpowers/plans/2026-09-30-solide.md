# Solide Implementation Plan

> For agentic workers: use superpowers:executing-plans in this session.

Goal: Local Windows application for variant selection, row-based QC, serial
database evidence and one workbook per patient.

Architecture: Python/PyQt6 desktop, normalized records preserving raw input,
atomic session checkpoints, separate provider adapters and report writer.
Reuse a pinned copy of Archer's Edge runtime and evidence service, removing
the lymphoid COSMIC filter and setting MTBP default to Other.

Tech Stack: Python >=3.11, PyQt6, openpyxl, requests, Pillow, websocket-client.
Spec: docs/2026-09-30-solide-forundersokelse.md.

## Global constraints
- hg19/GRCh37 explicit; unknown assembly blocks genomic searches.
- Coverage <500 is evaluated on each numeric row; unique genes summarized.
- CNV <1 fails; CNV =1 is a manual-review status pending laboratory definition.
- RNAExonTiles NO CALL and RNAExonVariant ABSENT included regardless of selection.
- Local identifiers never sent to evidence providers.
- Failed or unverified evidence never becomes a negative database finding.

## Review focus
- Fraction versus percent AF, blank trailing columns and metadata/header detection.
- Multiple transcripts, missing REF/ALT, identity mismatch and negative-strand indels.
- Patient/file-name mismatch, duplicate imports and assay QC scope.
- Locked workbook, malformed session, cancellation and partial screenshots.
- Stale evidence after a nomenclature or tissue change.
