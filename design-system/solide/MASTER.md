# Solide UI

Native PyQt6 clinical laboratory workbench. ui-ux-pro-max's Data-Dense Dashboard
recommendations are adapted to a local desktop app and the requested moss green
and white palette. No web framework, remote fonts or decorative animation.

Primary #425B3D; surface #FFFFFF; background #F5F7F4; text #243128;
muted #596454; border #DEE5DA; review #FFF2D5; failure #FCE5E3.
Segoe UI body 14px, headings 28px, secondary status 12px.

White 190px navigation rail, consistent stroke icons, green active item.
Compact header with session counts. Rounded surfaces (8–10px), 14px layout gaps,
44px action buttons, 36px table rows, visible keyboard focus and explicit status
text alongside colour. Native accessible table models and numeric sorting.

English pages: Import, Quality, Variants, Sources, Reports, Settings.
Variant details, source data and identity review use tabs. Activity logs expand
on demand. Secondary explanations live in tooltips and documentation; keep
action labels and necessary review / error states visible.

Check all pages at 1440×940 and 1050×700 using synthetic data. Wide scientific
tables retain native horizontal scrolling rather than hide source columns.
