# Solide UI

Desktop clinical laboratory review workspace, Data-Dense Dashboard from
ui-ux-pro-max, adapted to user-specified moss green and white.

Primary #425B3D; white #FFFFFF; background #F4F6F2; text #1F2A22;
muted #596454; border #D6DED2; review #FFF2D5; error #FCE5E3.
Segoe UI, 14px minimum body; Consolas for HGVS where useful.
Native labeled buttons and checkboxes, visible keyboard focus, native accessible
table model, numeric sort, fixed navigation and source provenance in details.
No decorative gradients, emoji icons, remote fonts or automatic interpretation.
Six pages: Import, Kvalitet, Variantutvalg, Databaseoppslag, Rapport, Innstillinger.
